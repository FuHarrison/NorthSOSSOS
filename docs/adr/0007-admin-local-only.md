# ADR-0007：後台只限本機

- 狀態：已接受（2026-11-20 追認現況）
- 日期：2026-11-20
- 決策者：開發者
- 對應需求：SYS-060～075、QS-041

## 背景
後台可以開新世界、刪世界、還原備份、刪帳號，是破壞力最大的操作；但不想另外做管理者帳號。

## 考慮過的選項
1. **管理者密碼**：任何電腦都能登入後台。
   - 切換代價：要做管理者帳號、登入狀態與 CSRF 防護；明文 http 下密碼會被看到（R7）。
2. **只限本機**：連線來源必須是 loopback、Host 標頭必須是 `localhost`、`127.0.0.1` 或 `[::1]`、會改變狀態的請求必須帶 `X-North-Admin: 1`。
3. （常見做法）**命令列工具**：管理功能做成 `node admin.js <指令>`，不提供網頁。
   - 切換代價：不用顧慮網頁安全；但不懂程式的主機管理者要打指令，違反 QS-013、QS-020 的「不用開終端機」。

## 決策
選項 2。

## 理由
- 主機管理者一定坐在主機那台電腦前，不需要遠端管理。
- 不用管理另一組密碼。
- Host 標頭擋 DNS rebinding；自訂標頭擋其他網頁的跨站請求（瀏覽器要先送預檢才能帶自訂標頭，而 server 沒有處理預檢，所以會失敗）。

## 後果
- 好處：區網的同事完全進不了後台；沒有密碼可以忘。
- 代價：主機管理者不能從別台電腦管理。
- 之後要注意：新的後台 API 都要經過 `localReq` 與標頭檢查；`adm` 訊息只接受 sim 送出；不要加上 OPTIONS 預檢的處理，否則自訂標頭就擋不住跨站請求。

## 重新檢視的條件
- 主機改放在沒有螢幕、沒人坐在前面的機器上。
- 需要讓主機管理者以外的人（例如輪值的同事）從自己的電腦管理。
