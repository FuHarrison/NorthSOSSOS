# 北境求生

一款在瀏覽器裡玩的俯視角生存遊戲。你在一片陌生的草原醒來，要砍樹、撿燧石、蓋營火、吃飽撐過夜晚，最後到石祭壇喚醒灰鬃狼王並打倒牠。

可以一個人玩，也可以在公司內網跟同事一起玩。

## 遊戲功能

### 寵物

- **野豬（採集型）**：帶著莓果靠近沒在生氣的野豬，按 E 餵牠。餵 5 次就會跟著你走，還會順手撿附近的石頭、燧石、莓果和蘑菇。
- **狼崽（戰鬥型）**：打倒狼王後，每個人都會得到一隻。速度快、傷害高。
- 寵物會跟著你，幫你攻擊附近的敵人。怪物平常不會主動打寵物，只有被寵物打到才會反擊。
- 寵物撿到的東西放在牠自己身上，可以到背包的「寵物」分頁一次取出。
- 寵物倒下時，身上的東西會掉在地上；60 秒後牠會在你身邊發著光復活。
- 寵物可以養很多隻，但一次只能召喚一隻。在「寵物」分頁可以召喚或收回。

### 背包與丟東西

- 背包是一格一格的正方形，每格顯示物品和數量；放在快捷欄的物品左上角會標出第幾格。
- 右鍵物品（觸控點一下）會跳出選單：吃、裝備／放快捷欄、丟出 1、丟出一半、全部丟出。
- 把物品拖出背包視窗，就會整格丟在地上。
- 武器、工具、皮甲都會顯示數值：傷害、攻擊距離、揮擊範圍、攻速、耐力消耗、砍樹和挖礦的力道、能挖哪些礦、減傷。製作卡片、背包選單、滑鼠停在格子上都看得到；左下角也會顯示手上武器的傷害。
- 丟出去的東西會變成地上的小袋子，任何人走過去按 E 都能撿起來。

### 地圖與迷霧

- 左上角的小地圖會顯示你附近的範圍。按 M 或點一下小地圖，可以打開整座島的大地圖。
- 地圖一開始是暗的，要親自走過才會亮開。沒去過的地方看不到建築，也看不到石祭壇。
- 地圖上會標出你自己、其他玩家、營火、工作台、床、熔爐、木牆、石牆和石祭壇。

### 牆壁

- 木牆和石牆都是薄薄一片，貼在格子的邊上。蓋牆時按 R（觸控按「轉向」）切換橫放或直放。
- 牆只擋住那條邊，旁邊的格子照樣可以走，也可以蓋工作台或營火。
- 牆可以連續放置，直到材料用完。木牆用 3 木頭，石牆用 4 石頭，都要在工作台旁邊蓋。
- 舊存檔裡的木牆會自動轉成新的樣子，原本圍起來的地方還是圍著。

### 挖礦與熔爐

- 島上有四種礦：煤礦、銅礦、錫礦、鐵礦。煤、銅、錫用燧石鎬就能挖；鐵礦要銅鎬。
- 鐵礦只出現在離出生點比較遠的地方。出生點附近一定有幾塊煤、銅、錫礦。
- 熔爐用 12 石頭、3 煤炭、6 木頭在工作台旁蓋。走過去按 E 打開，放進礦石和煤炭就會開始燒。
- 每 6 秒燒好一塊金屬錠。一塊煤炭燒 20 秒，點著了就會一直燒到完，所以礦石最好一次放夠。
- 銅錠可以做銅鎬（3 銅錠、4 木頭）。錫錠和鐵錠目前還沒有用途。
- 多人模式中熔爐是大家共用的，誰都可以放東西進去、取出成品。

### 範圍攻擊

- 一次揮擊會打到扇形範圍內所有的敵人、樹、石頭和礦，不只打最近的一個。揮擊時畫面上會顯示攻擊範圍。
- 範圍內沒有東西可以打時，才會撿起最近的小石頭、燧石這類小東西。

### 建造模式

- 按 B（觸控點右上角「建造」）進入建造模式。快捷欄會換成建築清單：工作台、營火、木牆、石牆、熔爐、床，最後一格是「拆除」。
- 用 1～8、滑鼠滾輪或 Q 選建築。每一格右上角的數字是用身上的材料還能蓋幾個，蓋不起的會變暗。
- 建造列會列出選中建築需要的材料、身上還剩多少，以及還能蓋幾個。
- 左鍵蓋、右鍵拆。也可以選「拆除」那一格，再用左鍵（觸控按攻擊）拆。要拆的建築會用紅框標出來。
- 拆掉建築會退回全部材料。拆熔爐時，爐裡的礦石、煤炭和成品也會一起退回。
- 蓋完一個不會離開建造模式，可以一直蓋。再按一次 B 或 Esc 離開。

### 快捷欄

- 畫面下方有 8 格快捷欄，選到的那格就是手上拿的東西。不用開背包就能換武器、工具或食物。
- 拿到新的武器、工具或食物時，會自動放進第一個空格。
- 背包下面有一排快捷欄：把物品拖上去就放進那一格，在快捷欄裡拖到別格會交換，拖出快捷欄就拿掉（東西還在背包）。
- 也可以用背包的選單「放快捷欄」，放進目前選的那一格。
- 選到食物時，按左鍵（觸控按攻擊）就會吃掉。
- 東西用完或丟掉後，那一格會自動清空。快捷欄會跟著存檔。

## 單人玩

直接用瀏覽器打開 `北境求生.html` 就能玩，不需要安裝任何東西。存檔會留在這個瀏覽器裡。

## 多人玩（區網）

### 當主機的人

1. 安裝 [Node.js](https://nodejs.org)，選 LTS 版。
2. 把 `北境求生.html`、`server.js`、`開主機.bat` 放在同一個資料夾。
3. 雙擊 `開主機.bat`。瀏覽器會自動打開遊戲，這個分頁就是主機。
4. 遊戲開始畫面和黑色的伺服器視窗都會顯示一個網址，例如 `http://10.x.x.x:8080`，把它傳給同事。

主機要注意：

- 主機的遊戲分頁和黑色的伺服器視窗都要一直開著，關掉就停止世界。
- 第一次啟動時，Windows 會跳出防火牆詢問，要選「允許」，同事才連得進來。
- 如果 8080 埠已經被別的程式占用，可以在終端機改用別的埠：`node server.js 8081`

### 加入的人

在瀏覽器網址列輸入主機給的網址，輸入名字，按「加入」就行。不需要安裝任何東西。

### 多人模式的規則

- 打開背包，或角色倒下時，世界**不會暫停**，怪物照樣會攻擊你。
- 任何人晚上睡覺，所有人都會一起跳到天亮。
- 打倒狼王後，每個人都會拿到狼王之牙和皮革。
- 每個人的背包、寵物和地圖探索範圍都存在自己的瀏覽器裡，世界進度存在主機的瀏覽器裡。
- 地圖迷霧是每個人各自的，同事走過的地方不會幫你打開。不過地圖上一定看得到其他玩家在哪裡。
- 地上的袋子大家都看得到、都能撿，但主機重開遊戲後就會消失。
- 主機離線後，其他人的畫面會等待。主機回來時，大家會自動重新連上。
- 想在同一台電腦測試的話，可以開兩個 `http://localhost:8080` 分頁，取不同名字。第一個分頁是主機，第二個分頁當成另一個玩家。

## 操作

| 動作 | 鍵盤滑鼠 | 觸控 |
|---|---|---|
| 移動／衝刺 | WASD 或方向鍵／按住 Shift | 在左半邊螢幕拖曳，推到底就是衝刺 |
| 攻擊、砍樹、採石（範圍內全部一起打） | 滑鼠左鍵（朝游標方向） | 按攻擊鈕（會自動瞄準） |
| 翻滾閃避 | 滑鼠右鍵或空白鍵 | 按翻滾鈕 |
| 互動（撿東西和袋子、餵野豬、烤肉、用熔爐、睡覺、獻祭） | E | 按互動鈕 |
| 快捷欄選格子 | 1～8 或滑鼠滾輪；Q 跳到下一個有東西的格子 | 點左下角的格子；「切換」鈕跳到下一格 |
| 背包／製作／寵物 | Tab | 點右上角按鈕 |
| 建造模式（蓋、拆建築） | B，再按一次離開；左鍵蓋、右鍵拆 | 點右上角「建造」鈕 |
| 蓋牆時轉向（橫放／直放，牆貼著格子的邊） | R | 按建造列的「轉向」鈕 |
| 大地圖 | M，或點小地圖 | 點左上角的小地圖 |
| 關閉視窗 | Esc | 點視窗右上角的 × |

## 檔案

| 檔案 | 用途 |
|---|---|
| `北境求生.html` | 整個遊戲 |
| `server.js` | 多人主機。只用 Node 內建功能，不需要 `npm install` |
| `開主機.bat` | 一鍵啟動主機，並打開瀏覽器 |
